# 🍽️ NLP-Based Food Ordering & Order Tracking Chatbot

An end-to-end **AI-powered food chatbot** built using **Natural Language Processing (NLP)** with Dialogflow, FastAPI, and MySQL, integrated into a real restaurant website.

---

## 🚀 Features
- NLP-based intent recognition using Dialogflow
- Order tracking using Order ID
- Context-aware conversations
- FastAPI webhook backend
- MySQL database integration
- Dialogflow Messenger embedded in website
- Responsive frontend UI

---

## 🧠 Tech Stack
- **NLP:** Google Dialogflow (Intents, Entities, Contexts)
- **Backend:** FastAPI (Python)
- **Database:** MySQL
- **Frontend:** HTML, CSS
- **Integration:** Dialogflow Web Messenger
- **Tunneling:** ngrok
