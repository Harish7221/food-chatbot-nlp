# 🍽️ NLP-Based Food Ordering & Order Tracking Chatbot

An end-to-end **AI-powered conversational chatbot** built using **Natural Language Processing (NLP)** that allows users to interact with a restaurant website for food ordering and order tracking.

This project demonstrates real-world usage of **Dialogflow NLP**, **FastAPI backend**, **MySQL database**, and **Dialogflow Web Messenger integration**.

## 🚀 Key Features

- 🧠 **NLP-powered conversation** using Google Dialogflow  
- 📦 **Order tracking using Order ID**
- 🔁 **Context-based conversations** (ongoing order & tracking)
- ⚡ **FastAPI webhook backend**
- 🗄️ **MySQL database integration**
- 🌐 **Dialogflow Messenger embedded in website**
- 🎨 Responsive frontend UI with HTML & CSS
- 🔐 Secure webhook communication using ngrok

---

## 🧠 NLP Capabilities

- Intent classification (track order, new order, add/remove items)
- Entity extraction (order_id, food items)
- Context handling for multi-step conversations
- Natural language understanding for user queries
